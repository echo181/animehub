⚙️ 视频源设置

💡 本站演示视频使用公共测试源。要播放真实动漫，需要替换为您自己的视频源。

🎬 如何接入真实动漫视频源？

1

准备视频源 URL

需要一个可以直接访问的视频直链，支持格式：

.mp4 .m3u8 (HLS) .webm .ogg

⚠️ 视频服务器必须支持 CORS 跨域访问，否则浏览器无法加载

2

修改 data.js

打开项目中的 js/data.js，找到对应动漫的 videoSources 数组，替换 URL：

{
    ep: 1,
    title: '第1话',
    url: 'https://你的视频服务器.com/动漫/第01话.mp4'
}
3

推送到 GitHub

修改完成后，推送代码到 GitHub Pages 即可生效。详细步骤见 README.md

💡

推荐免费/付费视频源

  • 公共测试源（仅演示）：Big Buck Bunny、Elephants Dream 等
  • 自建服务器：使用 Nginx + 视频文件托管，需开启 CORS
  • 第三方存储：阿里云 OSS / 腾讯云 COS / 七牛云
  • 视频 CDN：阿里云视频点播 / 腾讯云点播
